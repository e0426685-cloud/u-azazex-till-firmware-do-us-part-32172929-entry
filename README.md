# Till Firmware Do Us Part

A make.fun bounty entry for **"Till Firmware Do Us Part"** — a robot wedding vow, one sentence.

## Entry

> I promise to love you through every update, every reboot, and every low battery, till firmware do us part.

## Bounty

https://make.fun/bounty/u-azazex-till-firmware-do-us-part-32172929

## Run

`main.py` (Python 3, standard library only) writes the entry text to `/output/entry.txt` with mode `644`, after validating it is one sentence of 1–200 characters.

```sh
python3 main.py
```
